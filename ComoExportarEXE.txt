COMO GERAR O STRAVINSKY PARA DISTRIBUIR
=======================================

Tudo é feito por um só comando, na pasta do projeto:

    build.bat            (ou:  .\build.ps1)

Gera, em C:\Builds\Stravinsky\release\ :
  - Stravinsky-Setup-<versão>.exe     instalador (por utilizador, sem administrador)
  - Stravinsky-<versão>-portable.zip  versão portátil (descompactar e abrir Stravinsky.exe)

O instalador precisa do Inno Setup 6:  winget install JRSoftware.InnoSetup
Sem ele, gera-se só o zip portátil.

A versão está em version.py.

PUBLICAR UMA VERSÃO NO GITHUB
-----------------------------
1. Fazer commit de todo o trabalho (git status sem alterações).
2. Executar, com o número da nova versão:

       release.bat 1.0.3

   O script verifica se há trabalho de outro computador por trazer
   (git pull), corre os testes, atualiza version.py, faz commit, cria a
   tag v1.0.3 e envia tudo para o GitHub.
3. O GitHub constrói o instalador e o zip e publica-os em "Releases"
   (10-15 min): https://github.com/jvpd90/Stravinsky_QDA/releases

Não criar a tag à mão: a tag e version.py têm de ter o mesmo número,
senão o GitHub recusa construir a versão.

Ficheiros: packaging\stravinsky.spec (PyInstaller), packaging\installer.iss
(Inno Setup), packaging\launcher.py (arranque do .exe).
Registo de erros da app instalada: %LOCALAPPDATA%\Stravinsky\stravinsky.log
